# Submitted manuscript figure references

These PNG files were extracted from the submitted manuscript DOCX and are retained **only as visual audit references**. They are not analysis inputs.

- `Figure_1_submitted.png`: map of candidate reference frameworks and Bioindicateur2.
- `Figure_2_submitted.png`: RSr and density distributions.
- `Figure_3_submitted.png`: Bioindicateur2 score distributions.
- `Figure_4_submitted.png`: four-site local contrast plot.

`analysis/03_regenerate_manuscript_figures.R` rebuilds the figures from the cleaned workflow. Figure 1 cannot reproduce the exact satellite/GIS background because the original GIS project or basemap source was not supplied; the point pattern is regenerated on a static France outline instead.
